# What You Need

Before you can start using your Red Pitaya board, you'll need the following items:

## Required Hardware

| Item | Description |
|------|-------------|
| Red Pitaya board | STEMlab 125-14, STEMlab 125-10, or SDRlab 122-16 |
| Micro SD card | Class 10 or higher, minimum 8 GB |
| Micro SD card reader | For flashing the OS image |
| Ethernet cable | For connecting to your router |
| Power supply | 5V/2A micro USB (or USB-C for newer models) |

## Required Software

- **balenaEtcher** or **Win32DiskImager** – for flashing the OS image to the SD card
- **SSH client** – PuTTY (Windows) or built-in terminal (macOS/Linux)
- A modern web browser (Chrome, Firefox, Safari, Edge)

## Optional Items

- USB-UART converter – for serial console access
- SMA cables and test probes – for signal measurements
- Enclosure/case – for protection

## Next Steps

Once you have all the required items, proceed to [First Steps](/docs/quick-start/first-steps) to set up your board.
